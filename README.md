# Employee Management API

A MuleSoft-based REST API for managing employee information.

## Technologies

- MuleSoft Anypoint Studio
- DataWeave
- MySQL
- REST API
- RAML
- MUnit
- Maven

## Features

- Create employee
- Get all employees
- Get employee by ID
- Update employee
- Delete employee
- Employee email validation
- Error handling
